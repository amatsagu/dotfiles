## Secure boot

- https://wiki.cachyos.org/configuration/secure_boot_setup/
- https://wiki.archlinux.org/title/Unified_Extensible_Firmware_Interface/Secure_Boot#Assisted_process_with_sbctl

## Firewall (for more secure network requests)
1. Install `ufw` (on CachyOS it likely is already installed):
```bash
sudo pacman -S ufw
```
2. Run provided commands to create basic configuration where most incoming requests will be blocked. These instructions are meant to be used by client stations (ignore if you plan to host applications like on dedicated server):
```bash
sudo ufw default deny incoming
sudo ufw default deny routed
sudo ufw default allow outgoing
sudo ufw enable
```

> [!WARNING]
> Be careful when configuring firewall rules, as improperly configured rules can lock you out of your own system.

## Avoid AUR packages and AUR helpers
I know they are very convenient but AUR has been frequently attacked in last months and amount of attacks is likely going to increase. Even when you're very careful - it's better to just search for alternatives. Just not using AUR makes your system far more "secure".

## AppArmor (increase power of local permissions, better controll apps' access)
Honestly, this is likely overkill but if You're willing to spend 2-5 hours then please read https://wiki.cachyos.org/configuration/post_install_setup/#apparmor-support-using-apparmord-profiles and https://gitlab.com/apparmor/apparmor/-/wikis/home. CachyOS's wiki only says how to start with AppArmor but by default it won't be very useful. Your main goal is to obtain profiles for all apps that interacts with outside network (discord, steam, various games, spotify, etc.). There's not much reason in writing profiles for local system tools or apps that you know always runs offline as thse are hardly ever targeted. There are large, community repositories with thousands of AppArmor profiles ready to be used but some of them are of low quality or are outdated so please be careful with them.

> [!TIP]
> My personal recommendation is to use Flatpaks for applications you don't trust such as AI agents, fancy SSH client, etc. Flatpak containers can provide similar level of security but are much easier to work with. Many apps already exists on repositories like Flathub but if not - it's easy to wrap regular application to be run in Flatpak.
