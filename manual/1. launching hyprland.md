<h2 align=center>Chapter 1</h2>
<h3>Launching Hyprland</h3>
</div>

> [!NOTE]
> In this chapter, we focus on installing all needed packages and launching default config of Hyprland with browser of your choice to make things easier to navigate. Everything we do will use standard CachyOS/Arch repositories, never AUR.
>
> This chapter should take max ~10-15 minutes.

1. Install Hyprland core packages:
```bash
sudo pacman -S hyprland hyprpolkitagent hypridle thunar gvfs gvfs-mtp udisks2 imv mpv wl-clip-persist xdg-desktop-portal xdg-desktop-portal-wlr xdg-desktop-portal-gtk xdg-desktop-portal-hyprland foot git fastfetch
sudo pacman -S --needed xdg-user-dirs
```
2. Install browser of your choice. I personally recommend Brave Origin - minimal, chromium based browser that is free on Linux: `sudo pacman -S brave-origin-bin`
3. Launch Hyprland (`start-hyprland`) for the first time and click through their new interactive tutorial. During tutorial - select `foot` as default terminal.
4. Download & compile latest Noctalia Shell v5+. It's very important to get v5 because they rewrote massive amount of code and now applets are natively written in C++ instead QT framework. Exact steps may change in future so it's best to follow official guide: https://docs.noctalia.dev/v5/getting-started/installation/?section=tab-panel-6#tab-panel-6.
    - We're doing everything "safely", which means no relying on AUR. Currently, You can achieve this by running:
    ```sh
    git clone https://aur.archlinux.org/noctalia-git
    cd noctalia-git
    makepkg -is
    ```

> [!TIP]
> We're all lazy here, my dotfiles focus around Hyprland + Noctalia Shell combo. All configuration is applied either by Noctalia or Hyprland and very rarely something else. Additionally - we try to keep things simple so when something eventually breaks - it's easy to fix. Remember - arch, hyprland and noctalia wikis are your best friends.
